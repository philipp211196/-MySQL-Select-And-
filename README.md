# Consultas e Comandos MySQL

> **Categoria:** Estudos de banco de dados · **Tecnologia:** SQL / MySQL

Repositório de exercícios e exemplos de consultas SQL, incluindo filtragem, ordenação, agrupamento, junções, subconsultas e procedimentos armazenados.

## Conteúdos encontrados

- `Atividade 1 a 34` — sequência de atividades.
- `SELECT + LIMIT e AVG`, `SELECT MIN`, `SUM +BETWEEN`.
- `Select + IN e OR`, `Select + Like 1 & 50`.
- `Select + Inner Join`, `Select + Subconsulta`.
- `ORDER BY, HAVING, GROUP BY, SELECT com INTO, Limit, Calculando valores, alias), CONCAT`.
- `Stored_Procedure` — estudos de procedimentos armazenados.
- `Criação de banco de dados` — material de estruturação de banco.

## Como utilizar

Abra o exercício desejado e revise as instruções antes de executá-las em um banco de dados de testes usando MySQL Workbench ou outro cliente MySQL. Alguns arquivos são materiais sem extensão `.sql` e podem precisar ser copiados para um editor SQL.

> **Cuidado:** comandos SQL podem alterar ou excluir dados; use um ambiente de testes. Os exemplos não foram validados para produção.
